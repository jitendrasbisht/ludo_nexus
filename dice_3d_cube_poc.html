Ludo Nexus — POC, feasibility check only

A real tumbling 3D cube instead of flat face-swaps

This is a genuine cube with 6 separate faces in 3D space, tumbling on rotateX/rotateY (pure CSS animation, loops automatically, no clicking needed) -- not the current approach of swapping a flat pip image every tick. It settles back on the "5" face every loop, standard die convention (opposite faces sum to 7: 1↔6, 2↔5, 3↔4).

Loops continuously, ~2.6s per roll -- in the real app this would run once per actual roll and land on whatever value the engine rolled, not always "5".
POC only. Feasible in Flutter using Matrix4 3D transforms (Transform.setEntry + rotateX/rotateY), but a real build needs 6 pre-built faces plus logic to compute the exact end rotation for each of the 6 possible results -- meaningfully more work than the current flat-swap DiceWidget. Worth it, or is the current 1-6 sequential cycle good enough?
